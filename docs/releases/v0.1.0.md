# SIMD v0.1.0

首个公开版本：Linux 下的多模组 SIM 短信管理与 Bark 转发服务。

## 下载

| 文件 | 适用平台 |
|---|---|
| `simd_v0.1.0_linux_arm64.tar.gz` | Orange Pi Zero 3，64 位 Debian / Ubuntu / Armbian，ARMv8.0 基础指令集 |
| `simd_v0.1.0_linux_amd64.tar.gz` | Linux x86-64 主机 |
| `SHA256SUMS` | 压缩包 SHA-256 校验值 |

均为无 CGO 静态构建，压缩包包含 `simd`、配置示例、systemd 文件、API 文档和部署指南；目标设备无需安装 Go。

## 功能

- 通过 UART 管理多个 ML307R，接收、保存、查询及发送单条短信。
- SQLite 保存短信与待转发任务，支持重启恢复、Bark 失败重试和手动补发。
- 简洁 Bark 通知：统一 Apple Messages 图标，`New Message` 标题，`号码 · 时间戳` 副标题及原始短信内容；通知时间固定为 Asia/Shanghai。
- Bearer Token API、health 检查、systemd 服务与私有数据目录。
- `simd -version` 显示版本、源码提交和构建时间。

Orange Pi Zero 3 安装步骤见压缩包中的 `docs/orangepi-zero3.md`，也可查看[仓库指南](https://github.com/JAX1024Dev/SIMD/blob/v0.1.0/docs/orangepi-zero3.md)。

## 使用前须知

正常启动会归档并清理模组中已有的短信，历史短信不推送；只读探测使用 `-probe-port <port> -probe-sms`。发送结果为 `unknown` 时不自动重发。

软件测试包含协议模拟、事务/重启恢复、API、Bark、本机进程冒烟及原生 Linux ARM64 CI。真实运营商收发、长短信固件行为、两实机并行、Zero 3 板卡接线及 24 小时稳定性仍需按 `docs/validation.md` 验收；本版本不将交叉编译或 CI 视为已完成板卡实测。

厂商原始资料、开发虚拟环境、凭证与运行数据库不包含在发布包中。
